CoachOS prototype v0.2 — coach: Sanidhi

Files:
- index.html — the whole app (self-contained, no build step)

Run locally:
- Just open index.html in a browser.

Deploy to Netlify:
- Drag this unzipped folder onto app.netlify.com/drop — done.

Go live (optional):
- Open the app, click "API key" (top-right), paste an Anthropic API key.
- The green "Sanidhi live" pill appears; drafts and coaching become LLM-powered.
- Without a key it runs in guided-demo mode.

Reset:
- "Reset demo" (top-right) clears local progress. The API key is kept.
